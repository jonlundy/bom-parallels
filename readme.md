# Compare KJV and Book of Mormon parallels

This project contains a normalized version of the KJV and Book of Mormon.
All punctuation was removed and spelling and capitalization has been normalized to better find the differences between the texts. I am using the current 2026 editions of the KJV and Book of Mormon.
